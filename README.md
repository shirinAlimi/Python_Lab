# Python Lab

This repository contains Python programming exercises, assignments, class activities, practice problems, and data-cleaning exercises completed as part of a Python programming lab.

The repository covers fundamental Python concepts as well as introductory data manipulation and cleaning using Pandas and NumPy.

## Repository Contents

### 1. Assignments

The `Assignments` folder contains Python programming assignments covering fundamental programming concepts such as:

* Lists
* Loops
* User input
* Arithmetic operations
* Conditional statements
* Functions and basic problem solving
* Temperature conversion
* Unit conversion
* Calculator programs
* Mathematical calculations
* Cricket score analysis

### 2. Class Activity

The `Class_Activity` folder contains exercises completed during class activities.

Topics include:

* Basic Python programming
* Working with Python data structures
* Reading and working with datasets
* Handling missing values
* Data cleaning
* Pandas DataFrames
* NumPy

This folder also contains sample student and sales datasets used for data-cleaning exercises.

### 3. Dictionary and Loop Lab

The `Dic_Loop_lab` folder contains exercises focused on Python dictionaries and loops.

The exercises provide practice with:

* `for` loops
* Iteration
* Dictionaries
* Number calculations
* Squares and cubes
* Input processing
* Basic problem solving

### 4. Pandas Lab

The `Pandas_Lab` folder focuses on data manipulation and data cleaning using **Pandas** and **NumPy**.

The exercises include:

* Reading CSV files
* Creating and manipulating DataFrames
* Removing duplicate records
* Handling missing values
* Cleaning text data
* Standardizing categorical values
* Converting data types
* Detecting and correcting invalid values
* Calculating statistics
* Creating cleaned datasets
* Saving processed data to CSV and Excel files

Two main datasets are used in these exercises:

* Student dataset
* Sales dataset

For example, the sales-cleaning exercise removes duplicate order IDs, standardizes month and region values, handles invalid quantities and prices, and calculates total sales.

## How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the repository:

```bash
cd Python_Lab
```

Run an individual Python file:

```bash
python Assignments/lab1.py
```

For the Pandas exercises, install the required libraries:

```bash
pip install pandas numpy openpyxl
```

Then run the desired Python script. For example:

```bash
python Pandas_Lab/sales_clean.py
```
